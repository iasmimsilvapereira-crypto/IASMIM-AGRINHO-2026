# Agro Forte, Futuro Sustentável - Nova Tebas 🌾✨

Este é um site informativo sobre a força econômica e a sustentabilidade do agronegócio no município de Nova Tebas, localizado na região Central do Paraná. O projeto destaca a importância da agricultura familiar, a inovação no campo e traz ferramentas completas de acessibilidade.

---

## 🚀 Funcionalidades

O site foi desenvolvido com foco na experiência do usuário e na inclusão, contando com:

* **Menu de Acessibilidade Flutuante**: Ferramentas para garantir que todos consigam navegar.
  * **A+ / A-**: Aumento e diminuição do tamanho das letras.
  * **Modo Contraste (🌓)**: Alternância entre o modo claro e o modo escuro.
  * **Leitura de Voz (▶ / ⏹)**: Opção para ouvir o texto escrito na página.
* **Design Responsivo**: O site se adapta bem em computadores, tablets e celulares.
* **Abas Expansíveis (Accordion)**: Seção interativa para mostrar os pilares da produção local sem poluir o visual.
* **Formulário de Inscrição**: Espaço para cadastro em seminários online.

---

## 🛠️ Tecnologias Utilizadas

As seguintes tecnologias foram usadas na construção deste projeto:

* **HTML5**: Para a estruturação de todo o conteúdo da página.
* **CSS3**: Para o estilo visual, cores, imagens de fundo e posicionamento dos elementos.
* **JavaScript**: Para dar vida aos botões de acessibilidade e ao menu expansível.

## 📂 Como Rodar o Projeto Localmente

Se quiser baixar e testar este projeto no seu computador, siga os passos abaixo:

1. Baixe os arquivos do repositório ou clone usando o terminal:
   ```bash
   git clone https://github.com
   ```
2. Abra a pasta do projeto no seu editor de código (como o VS Code).
3. Certifique-se de que os seguintes arquivos estejam na mesma pasta:
   * `index.html`
   * `style.css`
   * `script.js`
   * As fotos (`Foto1.png`, `Foto2.png`, `Foto3.png`)
4. Dê dois cliques no arquivo `index.html` para abrir o site no seu navegador.

## ♿ Importância da Acessibilidade neste Projeto

A acessibilidade web garante que pessoas com deficiência visual, baixa visão ou outras limitações consigam acessar as informações sobre o agronegócio de Nova Tebas. O uso de tags como `role="complementary"`, `aria-label` e o desenvolvimento dos botões de controle de texto e voz foram pensados para tornar a internet um espaço mais democrático e inclusivo.
